# Portfólio — Yuri Portela

Site estático (sem build). Publicado na Vercel.

## Estrutura
- `index.html` — página e textos (PT/EN no bloco `COPY`, perto do fim do arquivo)
- `support.js` — runtime da página (não editar)
- Imagens locais (foto e case de posições) já estão embutidas no `index.html`

## Editar textos
Abra `index.html`, procure o texto (Ctrl/Cmd+F) e altere só o que está entre aspas, nas versões `pt` e `en`.

## Deploy
Vercel → Add New → Project → importar este repositório → Framework Preset: **Other** → Deploy.
Cada commit na branch principal publica automaticamente.
